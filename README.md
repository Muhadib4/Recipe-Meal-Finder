# Savora — Recipe & Meal Finder

An editorial-style recipe discovery experience built with HTML, CSS, and JavaScript. Savora combines a premium responsive interface with live recipe data from the free [TheMealDB API](https://www.themealdb.com/api.php).

## Features

- Load the full global recipe catalog from A–Z, with hundreds of dishes
- A much larger home collection assembled from six major food categories
- Search meals by name across live and locally curated recipes
- Live image suggestions while typing
- Browse by food category, cuisine, region, or any available main ingredient
- Sort every result collection by featured order, A–Z, or Z–A
- Six one-tap mood collections and full-sized regional collections
- Explore all-world, Indonesia, UK/England, Europe, Asia, the Americas, and Mediterranean/MENA collections
- Six built-in Indonesian recipes: Nasi Goreng, Rendang, Soto Ayam, Gado-Gado, Sate Ayam, and Rawon
- Switch the interface between English, Bahasa Indonesia, Spanish, and French
- Complete ingredients and cooking instructions
- Random recipe inspiration
- Favorites saved in browser local storage
- Recently viewed recipes saved locally for quick access
- Interactive ingredient checklist inside every recipe
- Grid and list browsing modes
- Light and dark themes with saved preference
- Shareable recipes and cooking video links
- Keyboard shortcut (`Ctrl/Cmd + K`) for search
- Responsive editorial layout, scroll animations, loading states, and error handling
- Animated scroll progress, premium hover depth, and reduced-motion support

## Run locally

No installation or API key is needed. Open `index.html`, or run:

```bash
npx serve .
```

## GitHub Pages

Go to **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`. The website will be available at:

`https://muhadib4.github.io/Recipe-Meal-Finder/`
